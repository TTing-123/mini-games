# GEAR — 齿轮

把齿轮池里的齿轮装进每一级，让传动比把输出指针停在目标刻度。

## 规则

- 输入轴固定转**一整圈**（360°）。
- 每级的比例是 **从动齿数 ÷ 主动齿数**，各级乘起来就是总传动比。
- 输出角 = 360° × 总比，再对 360° 取余；每级啮合会反向一次。
- 齿轮池里**每个齿轮只能用一次**，多余的齿轮可以不装（槽位比齿轮少时）。

## 操作

- 点零件盘里的齿轮选中，再点空槽装上。
- 点已经装好的齿轮可以拆下来。
- 提示：闪一下某个可行装配里的第一步。
- 输出角实时显示在刻度盘上，高亮刻度是目标。

## 关卡

10 关，全部由 `tools/level-forge.mjs` 反查、`tools/level-audit.mjs` 复核（可达 + 解数最少）：

0. 一半（1 级 · 12/6 · 180°）教学
1. 三分之二（1 级 · 6/9 · 240°）
2. 挑两个（1 级 · 6/9/24 · 90° · 6 种装配里只有 1 种对）
3. 两级（2 级 · 6/9/12/15 · 120°）
4. 五只齿轮（2 级 · 6/6/9/12/18 · 60° · 5 个齿轮只用 4 个）
5. 减速两级（2 级 · 6/9/9/12/36 · 240°）
6. 三级（3 级 · 6/6/12/15/24/36 · 120°）
7. 大齿轮（3 级 · 6/6/15/18/24/30 · 60°）
8. 双 9（3 级 · 6/9/9/18/18/30 · 90°）
9. 齿轮箱（3 级 · 9/12/15/15/24/24 · 105°）

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/gear/
```

调试信息：

```text
http://localhost:8080/gear/?debug=1
```

## 工具

```powershell
node gear/tools/level-audit.mjs                        # 逐关体检：可达角度、解的数量、查重
node gear/tools/level-forge.mjs <级数> <池大小> [最少解] [最多解]   # 反查哪些齿轮池让目标解数最少
node gear/tools/browser-check.cjs                      # 桌面 + 手机端到端检查
```
