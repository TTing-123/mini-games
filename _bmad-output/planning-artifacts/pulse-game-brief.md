# Pulse Game Brief

## Essential Experience

玩家通过一次瞄准，让物理系统自行产生超出预期的连锁结果。

核心幻想：不需要背规则，只需要观察颜色、轨迹和碰撞结果。每次发射都能立即理解发生了什么。

## Core Loop

观察当前关卡 → 瞄准并预览方向 → 发射弹球 → 物理和机关连锁结算 → 观察结果 → 调整下一发

## 三关渐进教学

### 第一关：发射与反弹

- 红核
- 蓝块高弹力反弹

### 第二关：引力弯曲

- 红核
- 蓝块
- 紫块引力井：明显弯曲轨迹，并显示牵引线

### 第三关：分裂连锁

- 红核
- 蓝块
- 紫块
- 黄块首次分裂
- 分裂球不可再次分裂

## Player Motivation

- 尝试不同发射角度
- 观察弹球产生连锁路径
- 用更少发射次数完成目标
- 利用引力改变轨迹
- 利用分裂制造多目标命中

## Scope

当前原型包含：

- 三个静态关卡
- 每关独立发射次数
- 一颗可分裂原始弹球
- 红核、蓝块、紫块、黄块
- 弹球轨迹、碰撞闪光、目标爆炸、引力脉动和镜头震动
- 胜负反馈和状态条

暂不包含：

- 剧情
- 正式美术
- 音乐
- 元进度
- 超过三关的扩展
- 3D
- 多人

## Success Metrics

- 玩家能通过自然碰撞理解蓝块反弹
- 玩家能观察到紫块对轨迹的影响
- 玩家能观察到黄块分裂效果
- 玩家愿意主动调整发射角度
- 至少出现一次弹球连锁摧毁多个目标
