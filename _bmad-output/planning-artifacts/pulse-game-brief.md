# Pulse Game Brief

## Essential Experience

玩家通过一次瞄准，让物理系统自行产生超出预期的连锁结果。

核心幻想：不需要背规则，只需要观察颜色、轨迹和碰撞结果。每次发射都能立即理解发生了什么。

## Core Loop

观察棋盘 → 瞄准并预览方向 → 发射弹球 → 物理与机关连锁结算 → 观察结果 → 调整下一发

## 颜色就是规则

- 红核：必须摧毁的目标
- 蓝块：高弹力反弹
- 紫块：吸引弹球，弯曲轨迹
- 白球：玩家弹球

后续可以加入：

- 黄块：分裂弹球
- 绿块：补充发射次数
- 灰块：可破坏障碍

## Player Motivation

- 尝试不同发射角度
- 观察弹球产生连锁路径
- 用更少发射次数完成目标
- 制造意外但合理的多次命中
- 优化自己的发射技巧

## Scope

首个原型只包含：

- 单屏封闭棋盘
- 一颗弹球
- 三次发射机会
- 三个红核
- 四个蓝色弹力块
- 一个紫色引力井
- 胜负反馈和发射次数显示

暂不包含：

- 剧情
- 正式美术
- 音乐
- 元进度
- 多关卡
- 3D
- 多人

## Success Metrics

- 玩家在第一发射击后立即理解红核是目标、蓝块会反弹
- 玩家愿意主动改变下一发角度
- 玩家能观察到引力对轨迹的影响
- 不依赖文字教程
- 至少出现一次弹球连续命中多个目标的连锁局面
