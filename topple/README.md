# TOPPLE — 拆塔

砖块只要还**连着地面**（上下左右连成一串）就稳；一旦断开，那一整坨会一起坠落。每关只给你几块砖的拆除次数，把**金块**送到目标格。

## 规则

- 点一块砖把它拆掉，金块不能拆。
- 拆完立刻结算支撑：与地面断开的连通块**整体下落**，落到别的砖或地面上；可能连着塌第二、第三次。
- 一整坨下落时是刚性的：落点由它下面**最高的那个障碍**决定。
- 金块停在闪烁的目标格上就赢；拆除次数用完还没到位就失败。

## 操作

- 点砖块拆除（金块不能点）。
- 提示：闪一下某个可行解里的下一块砖。
- 重来会恢复所有拆除次数。

## 关卡

10 关手写，目标格由 `tools/level-forge.mjs` 反查（金块可达落点 + 所需次数）后锁定，再由 `tools/level-audit.mjs` 复核：

0. 拆一根（1 次 · 教学：方块可以横着挂在柱子上）
1. 剪两边（2 次 · 两边都撑着，都要断）
2. 先清路（2 次 · 下面挡着一块）
3. 宽梁（2 次 · 整根横梁一起落，落点看最高的障碍）
4. 两级台阶（2 次）
5. 深井（2 次）
6. 高柱（2 次 · 先落到架子上，再抽掉架子）
7. 楼梯（3 次）
8. 高塔（3 次）
9. 大拆除（4 次）

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/topple/
```

调试信息：

```text
http://localhost:8080/topple/?debug=1
```

## 工具

```powershell
node topple/tools/level-audit.mjs                   # 逐关体检：可解、最少拆除次数、起始是否已成立、布局查重
node topple/tools/level-forge.mjs <结构文件> [次数]   # 反查金块可达落点与所需拆除次数（用来定目标格）
node topple/tools/browser-check.cjs                 # 桌面 + 手机端到端检查
```

结构文件就是去掉目标格的地图（`#` 砖、`G` 金块、`.` 空）。
