# TOPPLE — 拆塔

砖块只要还**连着地面**（上下左右连成一串）就稳；一旦断开，那一整坨会一起坠落。每关只给你几块砖的拆除次数，把**金块**送到目标格。

## 规则

- 点一块砖把它拆掉；金块和**钢砖**（灰色、带铆钉）不能拆。
- 拆完立刻结算支撑：与地面断开的连通块**整体下落**，落到别的砖或地面上；可能连着塌第二、第三次。
- 一整坨下落时是刚性的：落点由它下面**最高的那个障碍**决定——那个障碍可能在别的列，不一定是金块正下方。
- 金块停在目标格上就赢；拆除次数用完还没到位就失败。

## 操作

- 点砖块拆除（金块 / 钢砖点不动）。
- 提示：闪一下某个可行解里的下一块砖。
- 重来会恢复所有拆除次数。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/topple/
```

调试信息：

```text
http://localhost:8080/topple/?debug=1
```

## 工具

```powershell
node topple/tools/level-audit.mjs                  # 逐关体检：可解、最少拆除、解条数、开局分支、难度分、布局与拆法查重
node topple/tools/level-forge.mjs <结构文件或目录> [次数]
                                                   # 反查每个可达落点需要几次拆除、有几条最短解、拆除的列偏移
node topple/tools/browser-check.cjs                # 桌面 + 手机端到端检查
```

结构文件就是地图（`#` 砖、`S` 钢砖、`G` 金块、`.` 空），不需要写目标格——目标格由锻造工具挑。
