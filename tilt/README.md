# TILT — 倾倒

往一个方向倒，整块板子倒过去：所有方块一起滑，撞到墙才停。正好停在凹槽上的方块会被吸收。把方块全部清空就过关。

## 操作

- 方向键 / WASD：往那个方向倒。
- 在棋盘上滑动：同上（手机）。
- 屏幕下方的方向按钮：同上。
- 提示：闪一下最短解法里的第一步。

## 规则

- 一次倾倒里，方块各自滑到撞墙、撞到别的方块为止。
- **停在凹槽上的方块会被吸收**；只是滑过凹槽不会被吸收。
- 同一格里仍然互相挡住，所以顺序很重要。
- 凹槽可以反复使用，一个凹槽也能收好几个方块。

## 关卡

手写关卡，全部用求解器验证过可解，最短步数写在括号里：

0. 一步（1）
1. 转角（2）
2. 凹槽（2）
3. 回廊（3）
4. 侧廊（4）
5. 深巷（5）
6. 双落（2）
7. 绕柱（5）
8. 长滑（5）
9. 回流（3）
10. 迷宫（6）
11. 分道（3）
12. 排队（6）
13. 夹缝（6）
14. 四连（5）
15. 深井（5）

## 评价

步数越少评价越高，等于最短步数就是三星。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/tilt/
```

调试信息：

```text
http://localhost:8080/tilt/?debug=1
```

## 工具

```powershell
node tilt/tools/level-report.mjs          # 逐关检查可解性与最短步数
node tilt/tools/level-lab.mjs <地形文件>   # 手绘迷宫时看"几步能停到哪一格"
```
