# TILT — 倾倒

往一个方向倒，整块板子倒过去：所有方块一起滑，撞到墙才停。正好停在凹槽上的方块会被吸收。把方块全部清空就过关。

## 操作

- 方向键 / WASD：往那个方向倒。
- 在棋盘上滑动：同上（手机）。
- 屏幕下方的方向按钮：同上。
- 提示：闪一下最短解法里的第一步。

输入不等动画：方向一按，盘面立刻改，动画只是追上去（连按不会丢手），这和 2048 的处理方式一样。

## 规则

- 一次倾倒里，方块各自滑到撞墙、撞到别的方块为止。
- **停在凹槽上的方块会被吸收**；只是滑过凹槽不会被吸收。
- 同一格里仍然互相挡住，所以倒的顺序很重要。
- 凹槽可以反复使用，一个凹槽也能收好几个方块。
- 31 关进入颜色章节：带色方块只进**同色**凹槽，琥珀色虚线凹槽谁都收。

## 评价

步数越少评价越高，等于最短步数就是三星。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/tilt/
```

调试信息：

```text
http://localhost:8080/tilt/?debug=1
```

## 关卡自检

```powershell
node tilt/tools/level-audit.mjs     # 逐关体检 + 查重：不可解、解法重复、墙体相似、镜像对称
node tilt/tools/level-report.mjs    # 只看可解性与最短步数
```

当前 52 关的结果：0 关不可解、0 组解法重复、0 组墙体相似（同尺寸内部墙 Jaccard < 0.7）、无重复布局。
这两条约束已经写进 `tests/tilt-core.test.mjs`，加关卡时会在 `npm test` 里自动拦住。

## 关卡设计工具

```powershell
node tilt/tools/level-forge.mjs <地形目录> [最少步数] [候选数]     # 单方块：手画墙，挑起点与凹槽
node tilt/tools/level-forge2.mjs <地形目录> <方块数> [最少步数] [候选数] [颜色列表]   # 多方块：手画墙与凹槽，挑方块起点
node tilt/tools/level-lab.mjs <地形文件>                          # 打印"几步能停到哪一格"的热力图
```

主题和墙体是手画的，工具只负责穷举起点、给出最短步数、按解法去重，方便挑出不一样的那一版。
