# POUR — 倒色

只做一个动作：点一根试管，再点另一根，把液体倒过去。目标是让每根试管只装一种颜色。

## 操作

- 点击一根非空试管：选中它。
- 点击另一根试管：把顶层同色液体倒过去。
- 目标为空管，或者目标顶层颜色相同，才能倒。
- 撤销：回退一步。
- R / 重来：重置当前关。

## 规则

- 每根试管最多装 4 格液体。
- 一次会倒出尽可能多的同色液体。
- 每根试管为空，或者装满 4 格同一种颜色，就算完成。
- 前 3 关会直接高亮“先点哪根、再点哪根”，没有独立教程页面。

## 关卡

10 个自动生成并验证可解的关卡：

1. 三色起步
2. 第一组循环
3. 四色登场
4. 多一个空管
5. 五色压力
6. 五色周转
7. 五色收紧
8. 六色挑战
9. 六色周转
10. 最后一管

## 评价

每关记录步数。步数越少，评价越高，最高三星。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/pour/
```

调试信息：

```text
http://localhost:8080/pour/?debug=1
```
