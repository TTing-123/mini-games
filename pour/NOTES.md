# POUR 设计与市场调研

## 每步玩家在判断什么

**从哪根试管倒出、倒进哪根试管，才能不把颜色次序弄死。**

这是单动作解谜：只有“倒”一个操作，但每倒一次都会改变顶层颜色和空管位置。

## 市场检查

使用：

```powershell
node tools/market-check.mjs 'water sort puzzle' 'liquid sorting puzzle' 'color sorting tubes'
```

结果：

- Steam：没有直接对应的 PC 商业头部作品。
- itch.io：有 Water Sort Puzzle、Liquid Lunacy、Sorty Tubes 等同类。
- GitHub：求解器和克隆很多，说明规则成熟、玩家一看就懂；但大多是工具或简单实现。

## 选择理由

前几款失败的方向都需要先解释一套新规则。POUR 反过来：

- 只有一个动作。
- 目标一眼能看懂。
- 难度来自液体顺序和空管分配，不来自操作复杂度。
- 前 3 关直接高亮可倒的源试管和目标试管，不做独立教程页。

## 原型检查

- 10 个关卡全部由程序生成，并用求解器验证可解。
- 逻辑测试：8 项通过。
- 自动浏览器：页面加载、试管高亮、点击倒色、步数更新均通过，无控制台报错。
- 真人试玩：等待首轮反馈。
