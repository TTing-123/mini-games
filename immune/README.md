# IMMUNE — 免疫

病毒每回合向外扩散一格，你每回合最多投一针；免疫区同样逐格扩散，**谁先占住格子，格子就归谁**。把所有人都盖住就算赢。

## 规则

- 每回合：**病毒先扩散**，免疫随后扩散。
- 被病毒占过的格子不会变回来——所以你必须提前一步。
- 病毒碰到人 → 立刻失败；所有人被免疫覆盖 → 立刻胜利。
- 疫苗只能投在地图上的**投放点**，每回合最多一针；投放点被病毒吞掉就不能再用了。
- 投放点的免疫从投针那一刻开始向外扩散，和病毒一样每回合一格。

## 操作

- 点投放点投一针（本回合限一针）；点「推进一回合」（或按空格）走一回合。
- 提示：闪一下某个可行解法里的下一针。
- 教学关会淡显「病毒下一回合会占到的格子」。

## 关卡

12 关手写，全部由 `tools/level-audit.mjs` 复核（可解、最少针数、每人余量、查重）：

0. 抢先（1 针 · 教学：免疫要比病毒更早碰到人）
1. 绕一圈（1 针 · 墙把路拉长）
2. 两个人（2 针 · 各需一针）
3. 两头夹（1 针 · 两个病毒同时压来）
4. 快投（1 针 · 近处的投放点会被先吞掉）
5. 错位（2 针 · 两人离得远）
6. 走廊（1 针 · 唯一投放点）
7. 四方（2 针 · 两病毒两人）
8. 窄门（1 针 · 两条路选一条）
9. 分兵（3 针 · 三个人三处）
10. 长路（2 针 · 墙把两侧隔开）
11. 最后一道（2 针 · 两个病毒各盯一个人）

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/immune/
```

调试信息：

```text
http://localhost:8080/immune/?debug=1
```

## 工具

```powershell
node immune/tools/level-audit.mjs      # 逐关体检：最少针数、每人余量、投放点会不会被吞、查重
node immune/tools/browser-check.cjs    # 桌面 + 手机端到端检查
```

`level-audit` 里的**余量**＝病毒到达回合 − 免疫到达回合 − 1：0 表示这一针必须第一回合就投出去。
