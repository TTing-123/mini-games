# NONO — 数织

根据每行每列的连续块数字，推理出哪些格子应该填色。所有格子都能纯靠逻辑推出，不需要猜。

## 操作

- 左键点击：点亮或取消点亮。
- 按住左键拖动：连续点亮或连续取消。
- 提示：直接给出一个必然格。

## 规则

- 行或列旁边的数字表示连续填色块的长度。
- 例如 `3` 表示这一行有一段连续 3 格填色。
- 多个数字表示多段，段与段之间至少空一格。
- 教程关会逐列高亮“数字对应的连续格”，照着点就能理解规则。
- 正式关的前 3 关还会高亮一个必然格。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/nono/
```

调试信息：

```text
http://localhost:8080/nono/?debug=1
```

## 测试

```powershell
node --test nono/tests/nono-core.test.mjs
```
