# NONO — 数织

根据每行每列的连续块数字，推理出哪些格子应该填色。所有格子都能纯靠逻辑推出，不需要猜。

## 操作

- 选择「填格」：点击格子填色。
- 选择「打叉」：点击格子标记空白。
- 可以按住拖动连续操作。
- 右键点击格子也可以打叉。
- 撤销：回退一步。
- 提示：直接给出一个必然格。

## 规则

- 行或列旁边的数字表示连续填色块的长度。
- 例如 `3` 表示这一行有一段连续 3 格填色。
- 多个数字表示多段，段与段之间至少空一格。
- 前 3 关会直接高亮一个必然格，并在对应线索上做提示。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/nono/
```

调试信息：

```text
http://localhost:8080/nono/?debug=1
```
