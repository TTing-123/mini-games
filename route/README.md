# ROUTE — 绘线防御

敌人从入口出现，沿着你画的路线走向核心。炮台固定在地图上，自动射击范围内的敌人。

## 玩法

- 按住并拖动，画一条从入口到核心的路线。
- 敌人会沿着路线前进。
- 炮台自动攻击，不需要手动瞄准。
- 线越长，敌人在炮台火力范围内停留越久。
- 墨水决定路线最大长度。
- 重画有短暂冷却，敌人不会等你。
- 炮台弹药有限，打空后会重新装填。路线要跟着有弹药的炮台走。

## 操作

在棋盘上按住鼠标或手指，画一条线，松手后路线立即替换。入口和核心会自动连接。

## 胜负

- 核心生命归零：失败。
- 撑过一波又一波：分数增加，敌人变快、变强、数量变多。

## 设计定位

前三款游戏的核心判断分别是：

- PULSE：什么时候、在哪里触发物理连锁。
- CASEBOOK：该信谁、用什么验证谁。
- ROUTE：把敌人往哪条路线引，才能最大化炮台输出。

ROUTE 不做普通塔防的“建塔位”判断。炮台位置固定，玩家每几秒要重新判断的是：**当前哪些炮台还有弹药、敌人在哪里、墨水还能画多长的路、要不要马上重画。**

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/route/
```

调试信息：

```text
http://localhost:8080/route/?debug=1
```
