# ROUTE 设计与市场调研

## 每步玩家在判断什么

**把敌人往哪条路线引，才能让它们经过还有弹药的炮台，并在墨水耗尽前守住核心。**

这不是一次性规划，因为敌人一直在走，炮台弹药一直在变，重画还有冷却。玩家每几秒都要重新判断：

- 哪座炮台还有弹药
- 敌人在哪里、离核心还有多远
- 新路线能不能在墨水上限内画完
- 现在重画是否来得及

## 市场检查

使用：

```powershell
node tools/market-check.mjs 'draw path tower defense' 'draw route defense game' 'path drawing defense game'
```

结果：

- Steam：三个关键词均没有直接对应的 PC 商业作品。
- itch.io：有 Maze Forge TD、Route to Loot、Draw The Path 等零散作品。
- GitHub：有 pathkeep 等少数实现，但没有把“实时重画 + 炮台弹药轮换”做成核心压力的头部作品。

## 差异

普通路径塔防通常是在出怪前画好路线，或者在固定格子上建塔。

ROUTE 的区别：

- 炮台位置固定，不需要建塔。
- 敌人实时沿当前路线移动。
- 玩家可以在敌人行进中重画路线。
- 重画有冷却，墨水有上限。
- 炮台弹药有限，必须把敌人引向还有弹药的炮台。
- 玩家不是一次规划，而是在实时压力下不断改线。
