# Blast

连锁爆破。**当前是手感原型**，只验证一件事：点一下看连锁炸开，爽不爽。

在线试玩：<https://tting-123.github.io/mini-games/blast/>

## 怎么玩

点任意一个球。爆炸会按距离逐个点燃周围的球，连锁一路传下去，1～2 秒内炸满全屏。
炸完之后球会重新铺满，可以一直点。

- `R` 或右下角 `RESET`：重新铺一屏球
- `M`：静音

## 现在有什么

- 96 个球缓慢漂移、互相让位
- 冲击波按距离延迟传播（连得越远越慢，看得清扩散过程）
- 爆炸音效是现场合成的，连锁越深音高越高，不需要任何音频素材
- 冲击波圆环、飞散粒子、屏幕震动、实时连锁计数

## 还没有什么

按约定，原型阶段不做关卡、不做失败条件、不做难度曲线。确认手感之后再决定加什么，可能的候选：

- 有限点击次数 + 清空目标（一局 30 秒）
- 球分大小，大球爆炸范围更大，点哪个变成策略
- 会再生的球、会熄灭的球，制造"来不及"的紧张感

## 跑起来

在合集仓库根目录：

```powershell
py -m http.server 8080
```

打开 `http://localhost:8080/blast/`。

## 测试

```powershell
node --test blast/tests/*.test.mjs
```

覆盖撒点数量、点击消耗、爆炸半径内外差异、连锁跨簇传播与自动收敛、漂移边界、空点无响应。

## 架构

- `src/blast-core.js`：纯逻辑（撒点、漂移、冲击波传播、连锁状态机）
- `src/game.js`：Canvas 渲染、音效合成、输入
- `src/style.css`：极简全屏布局
