# SURGE — 推潮棋

一个 7×7 的抽象棋：每回合落下一枚棋子，然后把它所在的整行或整列推一格。棋子被推到边界外会消失。

- 青线从顶边连到底边即获胜。
- 琥珀线从左边连到右边即获胜。
- 玩家执青线，AI 执琥珀线。

## 操作

首次打开会自动显示 3 步引导。点右上角「怎么看」可以重看，并选择从第一步开始。

按住任意空格，向行或列方向拖动，松手即可落子和推线。拖动方向决定推哪一条线以及往哪边推。

## 规则

1. 选择任意空格。
2. 把该空格所在的行或列整条推移一格。
3. 推出去边界的棋子消失。
4. 青线上下连通，或琥珀线左右连通，立即获胜。

## 设计定位

前两款游戏的核心判断分别是：

- PULSE：什么时候、在哪里触发物理连锁。
- CASEBOOK：该信谁、用什么验证谁。
- SURGE：把棋子落在哪里，以及把哪条线推向哪边。

SURGE 不是“把相邻棋子推开”的 Push Fight / Boop 变体。它的动作是**整行或整列推移**，目标也不是单纯把对方推光，而是利用不断移动的棋盘建立跨边界连线。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/surge/
```

带调试信息：

```text
http://localhost:8080/surge/?debug=1
```

## 测试

```powershell
node --test surge/tests/surge-core.test.mjs
```

根 `npm test` 会同时跑 PULSE、CASEBOOK 和 SURGE。
