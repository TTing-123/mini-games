# SWAP — 换位

WASD 移动，点击视野里的箱子、敌人或钥匙，和它交换位置。目标是在换位、尖刺、坑和开关之间找到一条路，拿到钥匙并走到出口。

## 操作

- WASD / 方向键：移动。
- 鼠标移动到目标上：高亮可交换对象。
- 点击目标：交换位置。
- R：重来当前关。

## 规则

- 交换必须有无遮挡的视线，并且在距离内。
- 箱子和敌人也能交换。
- 箱子会被坑吞掉并填平坑。
- 敌人被换到尖刺或坑上会消失。
- 箱子放到开关上会打开门。
- 拿到钥匙后走到出口过关。

## 关卡

1. 跨过缺口
2. 跨过尖刺
3. 压住开关
4. 借敌人过坑
5. 组合换位

## 设计定位

SWAP 的核心判断不是“怎么打”，而是：

> 现在和谁交换位置，才能让自己到达下一个关键点，同时改变对方的位置。

它既是动作冒险，也是谜题：移动和敌人追逐带来实时压力，换位和开关带来空间推理。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/swap/
```

调试信息：

```text
http://localhost:8080/swap/?debug=1
```
