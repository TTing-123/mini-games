# Prism

光路与颜色的解谜。**当前是核心玩法原型**：一个场景，够摸清规则并开始规划光路。

在线试玩：<https://tting-123.github.io/mini-games/prism/>

## 规则

1. 白光从光源射出，射进棱镜会被**拆成红、绿、蓝三束**，各自偏一点角度散开
2. **镜子把光反射过去**
3. 目标要点亮，需要照到它的光**刚好**是它要的颜色——多一点少一点都不算

第三条是关键：既不能错色，也不能混进别的颜色。红+绿同时照到一个黄色目标才算数，只照到红不行；而红光照到绿色目标更不行。

## 关卡

| 关卡 | 教什么 | 镜子 | 目标 |
| --- | --- | --- | --- |
| 第一关 | 拖动与翻面，三色各归各位 | 2 | 红 / 绿 / 蓝 |
| 第二关 | 一束光能连续穿过两个目标 | 1 | 绿 ×2 |
| 第三关 | 两个颜色同时照到才算对上 | 1 | 黄（红+绿） |
| 第四关 | 墙挡住就绕过去 | 2 | 绿 |

每一关的解都由 `solveLevel()` 搜索验证过，测试里也固化成断言，不会出现无解关卡。

## 操作

- **拖动镜子**：换位置，光路实时跟着重算
- **轻点镜子**：翻面（`/` ↔ `\`）
- `空格` / `回车`：过关后进入下一关
- `R`：重置当前关卡

因为每次改动都立刻重算，你可以一边拖一边看光的走向，不用猜、不用提交等结果。

## 测试

```powershell
node --test prism/tests/*.test.mjs
```

覆盖：射线与线段/圆求交、45 度镜面反射方向、棱镜分光、颜色严格匹配（错色不算、混色要对齐）、墙挡光、关卡流程，以及**每一关都能在给定镜子数下解出来**。

## 架构

- `src/prism-core.js`：纯几何与光路追踪（射线求交、反射、棱镜分光、颜色按位叠加），不访问 DOM
- `src/game.js`：Canvas 渲染（光束用 `lighter` 混合，红绿重叠处自然变黄）、拖拽与翻面交互
- `src/style.css`：极简全屏布局
