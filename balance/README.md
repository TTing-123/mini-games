# BALANCE — 悬挂平衡

一个不需要解释目标的物理解谜游戏：把重物挂到钩子上，让所有横杆保持水平。

## 规则

- 圆形数字表示重量。
- 横杆会向力矩更大的一边倾斜。
- 离支点越远，同样的重量产生的力矩越大。
- 下面横杆上的总重量会传到上面的横杆。
- 拖动重物到空钩子上；把重物拖回下方托盘可以取下。

所有横杆同时水平即过关。

## 当前内容

12 个手写关卡：

1. 一边一个
2. 离得远更重
3. 两边一起算
4. 下面先稳
5. 重量传上去
6. 两根一起挂
7. 左右各一杆
8. 长链传递
9. 多个挂点
10. 先挂下面，再补上面
11. 两棵树
12. 长链多挂点

## 设计定位

前两款游戏的核心判断分别是：

- PULSE：什么时候、在哪里触发物理连锁。
- CASEBOOK：该信谁、用什么验证谁。
- BALANCE：哪个重物挂到哪个钩子，才能让整棵悬挂结构同时水平。

BALANCE 不是普通天平找假币，也不是把两侧总重量配平。它是多根横杆组成的悬挂结构：下面横杆的总重量会继续影响上面横杆的力矩，必须先让底层稳定，再逐层向上平衡。

## 本地运行

在仓库根目录：

```powershell
py -m http.server 8080
```

打开：

```text
http://localhost:8080/balance/
```

调试信息：

```text
http://localhost:8080/balance/?debug=1
```

## 测试

```powershell
node --test balance/tests/balance-core.test.mjs
```

根 `npm test` 会同时跑 PULSE、CASEBOOK 和 BALANCE。
